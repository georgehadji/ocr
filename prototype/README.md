# OmniOCR Prototype

This directory contains prototype/exploratory code that predates the
`packages/omniocr/` shared core library.

- `ocr.py` — Original Streamlit prototype: Tesseract ensemble (grc+ell+eng),
  2-pass PSM voting, OpenCV UMat preprocessing, DOCX/PDF export.

For new development, use `packages/omniocr/` or the edition composition
roots in `editions/`.
